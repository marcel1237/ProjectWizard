Estes arquivos documentam os presets incorporados em `CloudTemplateCatalog`. Cada capability é resolvida para todos os provedores selecionados pelo usuário.

Use um template pela CLI:

```bash
java -jar target/cloudwizard-0.1.0-SNAPSHOT.jar ./output meu-projeto serverless-api
```

Os templates são independentes de fornecedor. A escolha entre AWS, Google Cloud, Azure, Oracle Cloud e IBM Cloud permanece no modelo do projeto.
